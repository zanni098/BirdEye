# BirdEye Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build BirdEye — a local-first hub that unifies sessions, memory, skills, plugins, MCP servers, credentials, usage, and task dispatch across 9 AI agent harnesses, with an interactive dashboard and memory graph — and publish it as public repo `zanni098/BirdEye`.

**Architecture:** TypeScript npm-workspaces monorepo. Read-only adapters normalize each harness's on-disk state into a JSON-file store at `~/.birdeye`. A Hono daemon serves REST + WebSocket + the built dashboard and spawns headless harness CLIs for task dispatch. An MCP server (stdio + HTTP) exposes shared memory/tasks/vault to every harness. Vite+React dashboard with a d3-force memory graph.

**Tech Stack:** TypeScript, npm workspaces, Hono, @hono/node-server, @hono/node-ws, @modelcontextprotocol/sdk, commander, Vite, React 18, d3-force, Vitest. Zero native deps.

## Shared contracts (all tasks import these — do not drift)

### `packages/core/src/types.ts` (exact)

```ts
export type HarnessKind =
  | 'claude-code' | 'claude-desktop' | 'codex' | 'opencode' | 'openclaw'
  | 'zcode' | 'gemini' | 'cursor' | 'continue' | 'generic';

export interface Harness {
  id: HarnessKind;
  name: string;                 // display name, e.g. "Claude Code"
  configPath: string;           // absolute dir scanned
  detected: boolean;
  health: 'ok' | 'warnings' | 'error' | 'not-found';
  warnings: string[];
  lastScanAt: string;           // ISO
  dispatch?: { command: string; args: string[]; kind: 'cli' } | { kind: 'manual' };
}

export interface SessionRecord {
  harness: HarnessKind; id: string; title: string;
  startedAt: string | null; lastActiveAt: string | null;
  messageCount: number | null; project: string | null;
}

export type MemoryType = 'user' | 'project' | 'feedback' | 'reference' | 'instruction' | 'note';

export interface MemoryRecord {
  id: string;                   // stable: `${sourceHarness}:${contentHash.slice(0,12)}`
  title: string; body: string; type: MemoryType;
  sourceHarness: HarnessKind; sourceFile: string;
  createdAt: string | null; tags: string[]; links: string[]; // [[link]] slugs
  contentHash: string;          // sha256 of normalized body
}

export interface SkillRecord  { harness: HarnessKind; name: string; description: string; path: string; }
export interface PluginRecord { harness: HarnessKind; name: string; version: string | null; enabled: boolean; }
export interface McpServerRecord {
  harness: HarnessKind; name: string;
  transport: 'stdio' | 'http' | 'sse' | 'unknown'; command: string | null;
}
export interface AgentRecord  { harness: HarnessKind; name: string; description: string; }
export interface EnvKeyRecord { harness: HarnessKind; key: string; sourceFile: string; } // NAMES only, never values

export interface UsageRecord {
  harness: HarnessKind; period: 'all-time';
  inputTokens: number | null; outputTokens: number | null; costUsd: number | null;
  sessions: number | null; source: 'logged' | 'estimated' | 'unknown';
}

export interface TaskRun {
  id: string; startedAt: string; endedAt: string | null;
  status: 'running' | 'succeeded' | 'failed'; exitCode: number | null; output: string;
}
export interface TaskRecord {
  id: string; title: string; briefing: string;
  status: 'todo' | 'claimed' | 'running' | 'done' | 'failed';
  assignedHarness: HarnessKind | null; createdAt: string; updatedAt: string; runs: TaskRun[];
}

export interface ScanResult {
  harness: Harness;
  sessions: SessionRecord[]; memories: MemoryRecord[]; skills: SkillRecord[];
  plugins: PluginRecord[]; mcpServers: McpServerRecord[]; agents: AgentRecord[];
  envKeys: EnvKeyRecord[]; usage: UsageRecord;
}

export interface GraphNode {
  id: string; kind: 'memory' | 'entity' | 'tag' | 'harness';
  label: string; harness?: HarnessKind; weight: number; memoryId?: string;
}
export interface GraphEdge { source: string; target: string; kind: 'link' | 'mentions' | 'topic' | 'source'; }
export interface MemoryGraph { nodes: GraphNode[]; edges: GraphEdge[]; }
```

### `packages/adapters/src/adapter.ts` (exact)

```ts
import type { HarnessKind, ScanResult } from '@birdeye/core';
export interface AdapterContext { home: string; /* user home dir — fixtures override */ }
export interface HarnessAdapter {
  kind: HarnessKind;
  name: string;
  candidatePaths(ctx: AdapterContext): string[];   // dirs to probe, first hit wins
  scan(ctx: AdapterContext, configPath: string): Promise<ScanResult>;
}
```

Rules every adapter obeys: never throw (scanner wraps anyway); missing files → skip + optional warning; all reads are read-only; `usage.source: 'unknown'` when the harness doesn't log usage; memory extraction uses `parseMemoryMarkdown()` from core for md files.

### Store API (`packages/core/src/store.ts`)

```ts
export class BirdEyeStore {
  constructor(baseDir?: string)                     // default: ~/.birdeye, override via BIRDEYE_HOME
  saveScan(results: ScanResult[]): void             // atomic write scan.json
  loadScan(): ScanResult[] | null
  saveTasks(tasks: TaskRecord[]): void; loadTasks(): TaskRecord[]
  canonicalMemories(): MemoryRecord[]               // dedup across harnesses (contentHash, then fuzzy title)
}
```

### Server route map (packages/server)

```
GET  /api/overview   → { harnesses: Harness[], totals: {...} }
GET  /api/scan       → ScanResult[]           POST /api/scan → rescan now
GET  /api/memories   → MemoryRecord[] (deduped canonical)
GET  /api/graph      → MemoryGraph
GET  /api/tasks      → TaskRecord[]           POST /api/tasks {title, briefing}
POST /api/tasks/:id/dispatch {harness}        → starts CLI run, output streamed on WS
GET  /api/vault      → { keys: string[] }     POST /api/vault {key, value}  DELETE /api/vault/:key
WS   /ws             → events: scan-updated | task-updated | task-output {taskId, chunk}
```

MCP gateway tools (both stdio pkg and HTTP): `memory_search {query}`, `memory_save {title, body, tags?}`, `task_list {}`, `task_claim {taskId, harness}`, `task_update {taskId, status, note?}`, `vault_get {key}` (value returned only over MCP, never REST).

## Phase 1 — Core (TDD, inline)

### Task 1: types + hashing + memory markdown parser
**Files:** `packages/core/src/{types,hash,memory-md}.ts`, tests in `packages/core/test/`.
`sha256hex(s)`; `normalizeBody(s)` (trim, collapse ws, lowercase for hashing only); `parseMemoryMarkdown(md, source)` → extracts frontmatter (name/description/type) or falls back to title-from-heading; extracts `[[links]]` and `#tags`.
- [ ] Failing tests → implement → pass → commit `feat(core): types, hashing, memory markdown parser`.

### Task 2: store + dedup
**Files:** `packages/core/src/store.ts`, `packages/core/test/store.test.ts`.
Atomic write (`tmp` + rename). Dedup: same contentHash → keep earliest-source record, merge tags; fuzzy: same normalized title & levenshtein(body)/len < 0.15 → merge.
- [ ] Tests (tmp BIRDEYE_HOME) → implement → commit `feat(core): JSON store with cross-harness dedup`.

### Task 3: memory graph builder
**Files:** `packages/core/src/graph.ts`, test.
Nodes: one per memory (weight = body length bucket 1–5), per harness, per tag, per entity (capitalized multiword phrases + `[[link]]` targets appearing ≥2 times). Edges: memory→harness `source`; memory→tag `topic`; memory→memory `link` when `[[slug]]` matches other's slugified title; memory→entity `mentions`.
- [ ] Tests → implement → commit `feat(core): memory graph builder`.

### Task 4: marker-block sync-back
**Files:** `packages/core/src/marker.ts`, test.
`injectBlock(fileText, content)` replaces text between `<!-- BIRDEYE:START -->`/`<!-- BIRDEYE:END -->` or appends block; idempotent; preserves all user content byte-for-byte outside markers. `renderMemoryPack(memories, {maxChars})` → md digest grouped by type.
- [ ] Tests incl. idempotency & preservation → implement → commit `feat(core): marker-block memory sync`.

### Task 5: vault
**Files:** `packages/core/src/vault.ts`, test.
AES-256-GCM; key = scrypt(passphrase || machineId, salt). `set/get/delete/list` (list returns names only). File `~/.birdeye/vault.enc`.
- [ ] Round-trip + wrong-passphrase tests → implement → commit `feat(core): encrypted vault`.
